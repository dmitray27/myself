# Версии приложения «Радиочат УПТС-РК1»

Ветка `devin/1788704342-core-review-fixes`. Все Flutter-версии — Android и Linux,
общаются с платой УПТС-РК1 (ESP32 / ESP32-S3) по Wi-Fi/WebSocket; между собой
кодом не связаны (каждая папка — самостоятельный проект).

## Сводная таблица

| Папка | Назначение | Прошивка | Сделана из | Что добавлено / убрано |
|---|---|---|---|
| `flutter/` | Базовый клиент для уже прошитой платы | базовая | — (эталон) | — |
| `flutter_info/` | Базовый клиент + политика конфиденциальности для магазина | базовая | `flutter/` | + `privacy/index.html` |
| `flutter_firmware/` | Базовый клиент + инструкция по прошивке и скачивание `.bin` | базовая | `flutter_info/` | + кнопки `developer_board`, `download` |
| `flutter_color/` | Базовый клиент + выбор цвета приложения (7 цветов радуги) | базовая | `flutter_info/` | + кнопка `palette` |
| `pro_version/` | PRO: прошивка + клиент (доставка, статистика, история, шифрование…) | PRO | `flutter_firmware/` + базовая прошивка | + функции 1, 2, 3, 4, 6, 7, 8, 10б |
| `pro_version_open/` | PRO без шифрования | PRO (та же) | `pro_version/` | – п. 7: ключ группы, `pointycastle`/`crypto` |

Все Android-сборки сейчас имеют один `applicationId` (`ru.dubinich.radiochat`) и
название «Радиочат» — на одном телефоне одновременно стоит только одна версия.

## Общее для всех версий

- **Контракт с платой** (иначе версии несовместимы): точка доступа `AFSK-TRX-xxxx`,
  шлюз `192.168.4.1`; HTTP `GET /ping`, `GET /info`, `POST /send`;
  WebSocket порт 81: `setName:<имя>`, `msg:<имя>:<id>:<текст>`, ответы
  `<имя>:<id>:<текст>`, `System:<текст>`, `hist:` (до 20 досланных сообщений).
  Лимит кадра 1024 байта UTF-8, пауза ≥100 мс после `setName`.
- **Терминология**: пользователю — «УПТС-РК1»; в коде/логах — ESP32.
- **Кнопка «Назад» (Android)**: диалог «Выйти из радиочата?» — Отмена / Свернуть
  (приложение в фоне, связь сохраняется) / Выйти (соединение закрыто,
  уведомления сняты). Тап вне окна = Отмена.
- **Кнопка «i»**: окно «О приложении» из `assets/info.json`, текст выделяется,
  меню «Копировать / Выделить всё».
- **Фоновая работа**: Kotlin foreground-сервис с уведомлением «Радиочат»,
  WifiLock; уведомления о новых сообщениях при свёрнутом приложении.
- Общие файлы: `chat_connection.dart`, `chat_controller.dart`, `chat_protocol.dart`,
  `message_store.dart`, `info_dialog.dart`, `screen_pro.dart`, `main.dart`;
  Kotlin `MainActivity.kt`, `ChatForegroundService.kt`.

## Версии

### `flutter/` — базовая
Клиент для платы с базовой прошивкой (`tx_rx_mes_200b_filter_verbose_wifi/`).
Чат, имя абонента, звук, статусы «отправляется / принято платой / ошибка» по
эху платы. Реальной доставки в эфире не показывает (базовая прошивка ACK не шлёт).
Своих файлов нет — все остальные базовые версии сделаны из неё.

### `flutter_info/` — базовая + приватность
То же, что `flutter/`, плюс `privacy/index.html` (политика конфиденциальности
для публикации в магазине). Код `lib/` идентичен `flutter/`.

### `flutter_firmware/` — базовая + прошивка
Из `flutter_info`. В AppBar после «i» две кнопки:
- `developer_board` — пошаговая инструкция прошивки с ПК через web
  (ESP Launchpad / esptool), текст в `assets/flash_info.json`;
- `download` — диалог выбора чипа (ESP32-WROOM / ESP32-S3) → открытие ссылки на
  `.bin` в браузере (`url_launcher`), файл попадает в «Загрузки».

Ссылки на образы — в `assets/flash_info.json`, блок `downloads`
(сейчас плейсхолдеры `https://example.invalid/...`). Свои файлы:
`lib/flash_dialog.dart`, `assets/flash_info.json`, `test/flash_dialog_test.dart`.

### `flutter_color/` — базовая + цвет
Из `flutter_info`. Кнопка `palette` в AppBar (звук · палитра · имя · выход):
диалог с семью цветами радуги (красный, оранжевый, жёлтый, зелёный, голубой,
синий, фиолетовый). Цвет применяется к теме, шапке и своим сообщениям,
сохраняется (`shared_preferences`, ключ `app_color`), по умолчанию зелёный.
Свои файлы: `lib/app_color.dart`, `test/app_color_test.dart`.

### `pro_version/` — PRO
Прошивка `firmware/` (ESP-IDF 6.0.1, esp32 и esp32s3) и клиент `flutter_pro/`
(из `flutter_firmware`). Требует PRO-прошивку на **всех** платах группы: базовая
и PRO несовместимы по эфиру (ACK-кадры).

Функции (номера — из исходного списка идей):
1. Статус доставки по эфиру: принято платой → ушло в эфир → доставлено (ACK
   от удалённой станции) / нет подтверждения / ошибка.
2. Автоповтор неотправленных с backoff, ручной повтор.
3. Статистика канала: занятость эфира, сигнал, преамбула, CRC (`/stat`, кадр `stat:`).
4. История на телефоне, поиск, экспорт в txt.
6. Полевой режим: тёмная тема, крупные кнопки и шрифт, ландшафт.
7. Шифрование AES-256-GCM общим ключом группы (плата пересылает как есть,
   без ключа — «[зашифровано: ключ не совпадает]»).
8. Смена SSID/пароля точки доступа платы из приложения (NVS, `/config`).
10б. Плата отвергает занятое имя (`System:name busy`); список станций в эфире
   по ACK (`peers:`).

Подробно: `pro_version/README.md` (протокол, кадры, ограничения),
`pro_version/TEST_REPORT.md`. Свои файлы: `lib/pro_panels.dart`,
`lib/history_store.dart`, `lib/group_cipher.dart`.

### `pro_version_open/` — PRO без шифрования
Полная копия `pro_version/` без п. 7: удалены `group_cipher.dart`, диалог
«Ключ группы», индикатор замка, зависимости `pointycastle`/`crypto`. Текст идёт в
эфир открытым; сообщения от PRO-абонентов с включённым шифрованием будут видны
как строка `#e1.…`. Прошивка `firmware/` байт в байт совпадает с PRO.
Подробно: `pro_version_open/README.md`, `pro_version_open/TEST_REPORT.md`.

## Сборка и проверка

```bash
export PATH=$PATH:<путь к flutter>/bin
./run_flutter_tests.sh          # analyze + test для flutter, flutter_info, flutter_firmware, flutter_color
                                # → flutter_test_report.txt
cd pro_version/flutter_pro && flutter analyze && flutter test        # 60 тестов
cd pro_version_open/flutter_pro && flutter analyze && flutter test   # 50 тестов

cd <версия> && flutter build apk --release      # Android
cd <версия> && flutter build linux --release    # Linux
```

Тестов на сегодня: flutter 20, flutter_info 20, flutter_firmware 25,
flutter_color 23, PRO 60, PRO open 50; `flutter analyze` чисто во всех.
После смены версии обязателен `flutter pub get` (наборы зависимостей разные).

Проверено в эмуляторе Android 14: кнопки «Назад»/«Свернуть»/«Выйти» (базовые
копии). Не проверено без железа: ACK-тайминги PRO в эфире, UI PRO в эмуляторе.

## Чего нет ни в одной версии (задел)

- 10а — профили нескольких плат, автоподключение к Wi-Fi платы.
- 5 — быстрые фразы («Принял», «SOS»), отправка координат GPS.
- 9 — проверка версии прошивки (`version` в `/ping`).
- Копирование сообщения из ленты чата, поиск (вне PRO), локализация EN.
- Общий Dart-пакет вместо шести копий (правки сейчас дублируются вручную).
